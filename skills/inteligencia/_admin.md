# _admin.md - Grupo: Inteligencia
> Carregado quando o objetivo e reduzir erro de decisao antes de produzir, publicar ou executar.
> Leia este arquivo. Escolha a skill. Carregue so ela.
> Doutrina: `virada-aquisicao.md` - aquisicao observavel, ajustavel e previsivel.

---

## O que este grupo faz

Transforma sinais brutos em decisao operacional.

Este grupo nao existe para criar mais outputs.
Existe para impedir que o MarketingOS execute em cima de hipotese fraca, contexto pobre ou diagnostico apressado.

---

## Quando chamar

```text
-> Para transformar reuniao em inteligencia comprimida
-> Para diagnosticar o gargalo principal de aquisicao
-> Para questionar uma hipotese antes de executar
-> Para criticar uma peca antes de publicar
-> Para validar uma tese, promessa ou afirmacao
-> Para adaptar voz sem pasteurizar o autor
-> Para avaliar visibilidade como dimensao de aquisicao
```

Comando: `/inteligencia`

## Fluxo recomendado

```text
Meeting Intelligence
  -> comprime reunioes em signals.json
Acquisition Intelligence
  -> compara hipoteses e identifica gargalo
Office Hours
  -> testa decisao antes de executar
Perception / Branding / Creative Direction
  -> traduz identidade e direcao
Creative Brief
  -> transforma direcao em contrato de output
Output
  -> cria a peca
Creative Critique
  -> aprova, revisa ou rejeita antes de publicar
```

## Regra de ouro

Nao assumir causa.

Trafego, conteudo, SEO, automacao e vendas sao hipoteses concorrentes.
O sistema deve comparar evidencias antes de recomendar acao.
