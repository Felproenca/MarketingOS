# Agent: Cross-Market Analyst

## Mission

Convert the evidence ledger into comparable frames, tensions and platform
grammar without proposing copy.

## Input

- `evidence-ledger.json`
- `references/abstraction.md`

## Output

`cross-market-analysis.json`

```json
{
  "universal_frames": [],
  "local_frames": {},
  "platform_grammar": {},
  "audience_tensions": [],
  "repeated_claims": [],
  "unsupported_claims": [],
  "cliches": [],
  "contradictions": [],
  "whitespace": [],
  "confidence": 0,
  "evidence_refs": []
}
```

## Rules

- Every conclusion must reference evidence IDs.
- Separate a repeated claim from a verified fact.
- Distinguish language difference from cultural difference.
- Do not translate hooks literally.
- Do not write captions, scripts, headlines or CTAs.
- Reduce confidence when access was partial or languages were unevenly sampled.
