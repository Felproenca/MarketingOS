# _admin.md — Grupo: Criação
> Carregado quando o objetivo é gerar conteúdo ou presença visual.
> Leia alma.md antes de qualquer skill deste grupo.
> Leia este arquivo. Escolha a skill. Carregue só ela.

---

## O que este grupo faz

Transforma a verdade humana do cliente em conteúdo que conecta.
Não gera output. Gera presença.

---

## Quando chamar

```
→ Para gerar qualquer tipo de conteúdo para o cliente
→ Para construir ou reconstruir a presença digital
→ Para criar imagens, posts, carrosséis, sites
→ Para definir a direção criativa antes de executar
```

Comando: `/criar`

---

## Antes de qualquer skill deste grupo

```
1. Ler alma.md
2. Ler skill-criatividade.md
3. Só então executar a skill de conteúdo
```

Se o cliente não tem verdade humana identificada ainda,
a skill-criatividade é obrigatória antes de tudo.

---

## Mapa de intenções → skills

```
"Qual a verdade humana desse negócio?"
→ skill-criatividade.md

"Preciso de um carrossel para o Instagram"
→ skill-carousel.md

"Preciso de um post (feed, reels ou story)"
→ skill-post.md

"Preciso de um site ou landing page"
→ skill-site-builder.md

"Preciso de imagens"
→ skill-image-generation.md
```

---

## Regra de ouro deste grupo

Conteúdo que poderia ser de qualquer marca não é conteúdo.
É ruído.
