## Princípios de UX

**1. Clareza de oferta acima de tudo**
O visitante sabe em 3 segundos o que é e para quem é. Se precisar rolar para entender o negócio, o hero falhou.

**2. A arquitetura da página é a prova do sistema**
Cada seção responde uma objeção antes de ela ser formulada. A ordem dos blocos não é estética — é argumental.

**3. Densidade progressiva**
Começa simples, aprofunda para quem quer. O scanner passa rápido e entende. O comprador para e lê tudo.

**4. Processo real como prova**
O site não promete — demonstra. Outputs reais do sistema aparecem como evidência, não como decoração.

**5. Nunca parecer landing page de agência**
Sem depoimentos genéricos, sem "anos de experiência", sem grade de logos de clientes inexistentes. A prova é o sistema funcionando em público.

## Arquitetura de Homepage

| Bloco | Objetivo | Conteúdo |
|---|---|---|
| **01 — Tese** | Posicionar antes de vender | A frase central: "Marketing com direção, não com esperança." Para quem é e para quem não é. |
| **02 — O problema** | Fazer o ICP se reconhecer | Nomear o sintoma: funciona às vezes, não sabe por quê. Sem usar vocabulário interno. |
| **03 — Por que acontece** | Revelar a causa | A lógica não unificada — cada parte construída por alguém diferente, com lógica diferente. |
| **04 — A diferença** | Diferenciar sem atacar | O que muda quando há percepção antes de produção. Mostrar o processo, não descrever. |
| **05 — O sistema em operação** | Prova pública | Build in public: perception.json, visual DNA, outputs reais. O sistema como evidência. |
| **06 — Para quem** | Filtrar o ICP | Ser explícito sobre quem é e quem não é o cliente certo. Filtro ativo de qualificação. |
| **07 — Próximo passo** | Converter | CTA para conversa (não compra direta). Diagnóstico como entrada. |

## Regras de Conversão

**CTA principal:** conversa, não compra imediata. "Agendar diagnóstico" ou "Conversar sobre o sistema" — nunca "Saiba mais" ou "Entre em contato".

**Repetição mínima de CTA:** 3 vezes ao longo da página.

**Filtro de ICP na hero:** dizer explicitamente para quem não é serve como qualificador e aumenta credibilidade com quem é.

**Objeções respondidas antes de serem perguntadas:**
- "Isso é diferente de agência?" → responder no bloco 04
- "Isso funciona para o meu negócio?" → responder no bloco 06
- "Quais são os resultados?" → responder no bloco 05 com honestidade sobre o estágio atual

---

## Densidade Visual

Equilibrado — substancioso sem ser denso. O site reflete a assinatura perceptiva: superfície acessível, profundidade disponível.

Cada bloco tem no máximo 3 elementos de atenção: headline, suporte e CTA ou evidência. Nunca encher.

---

## Mobile First

Sim — a maioria do ICP vai ver primeiro pelo celular.

Hierarquia no mobile: headline → subheadline → CTA. O desenvolvimento vem depois para quem continua lendo.
