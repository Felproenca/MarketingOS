# _admin.md — Grupo: Aquisição
> Carregado quando o objetivo é encontrar e converter novos clientes.
> Leia este arquivo. Escolha a skill. Carregue só ela.

---

## O que este grupo faz

Encontra as pessoas certas, no momento certo,
com a mensagem certa para iniciar uma relação comercial.

---

## Quando chamar

```
→ Para encontrar prospectos em um nicho
→ Para estruturar como capturar leads
→ Para posicionar e comunicar a oferta
→ Para criar a apresentação comercial
→ Para pesquisar mercados com potencial
```

Comando: `/prospectar`

---

## Mapa de intenções → skills

```
"Quais mercados têm potencial agora?"

"Quem são os clientes ideais nesse nicho?"
→ skill-prospector.md

"Como estruturo a captura de leads?"
→ skill-lead-capture.md

"Como posiciono e comunico a oferta?"
→ skill-offer-positioning.md

"Preciso de uma apresentação para prospectar"
→ skill-pitch-deck.md
```

---

## Fluxo natural deste grupo

```
skill-market-analyzer
  → identifica o nicho
skill-prospector
  → encontra os clientes
skill-offer-positioning
  → define a mensagem
skill-pitch-deck
  → gera a apresentação
skill-lead-capture
  → estrutura a captura
```

---

## Regra de ouro deste grupo

Quantidade de prospecto sem qualificação é desperdício.
Sempre qualificar antes de abordar.
