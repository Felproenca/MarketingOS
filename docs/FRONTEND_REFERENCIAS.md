## Como usar uma referência

Ao estudar uma interface, registre somente o que será aplicado no MarketingOS:

1. **O que observar:** layout, fluxo, componente ou interação.
2. **O que copiar:** comportamento específico que resolve um problema do Cockpit.
3. **Onde aplicar:** página ou componente do frontend.
4. **Decisão:** aplicar agora, deixar para depois ou descartar.
