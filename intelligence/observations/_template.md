# _template.md — bloco de observação
> Copie o bloco abaixo para o topo de observations.md a cada nova observação.
> Único campo obrigatório: o contraste. O resto preenche só se existir — nunca inventa.

```
### [OBS-XXX] — [nome curto, ex: "construtora-acha-que-é-tráfego"]

Data:        [ AAAA-MM-DD ]
Fonte:       [ reunião / objeção / diagnóstico / prospecção — com quem (slug ou nome) ]
Contexto:    [ 1 linha: setor, porte, como o assunto surgiu ]

— CONTRASTE (obrigatório) —

O que ELE acredita ser o problema:
→

O que ENCONTRAMOS (ou suspeitamos, com base em quê):
→

— LIVRE (só se existir) —

Como ele chegou nessa conclusão:
→

Sintomas observados (frases dele, dados, sinais):
→

Convergem ou divergem?   [ convergem / divergem / cedo demais ]

Próxima ação comercial que isso destrava:
→
```

---

## Notas de uso

- **Pergunta de abertura sugerida em reunião:** "O que você acredita que está
  impedindo seu crescimento?" → depois: "Como você chegou nessa conclusão?"
- **No diagnóstico**, adicionar a seção: *"O que você acredita ser o problema ↓
  o que encontramos."* É a mesma medida, dentro da entrega.
- Se a observação não tiver o contraste, **ela não é uma observação ainda** — é
  uma nota. Notas vão para o notes.md do cliente, não para cá.
