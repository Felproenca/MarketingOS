# Instagram Funnel Playbook

> Doutrina completa: `intelligence/doutrina-instagram-operacao.md`
> Cultural default BR: `cultural-playbooks/brazil-latam.md`
> Conversação: `conversational-commerce.md`

Instagram deve ser tratado como:

```text
portfolio vivo
prova publica
motor de confianca
entrada para DM/WhatsApp
ambiente de valor, nao so venda
camada publica de um dominio privado (Broadcast / CF / WA / e-mail)
```

---

## Funis Recomendados

```text
Post de tensao -> comentario -> ManyChat -> checklist -> mini diagnostico -> WhatsApp
Reels de bastidor -> DM -> analise rapida -> diagnostico
Carrossel educativo -> salvar -> lead magnet -> nutricao
Prova/antes-depois -> formulario -> diagnostico
Live de problema -> keyword -> asset -> WhatsApp
Broadcast/Close Friends -> oferta densa -> conversa quente
```

---

## CTAs Recomendados

```text
comente palavra-chave
mande seu site
responda com seu nicho
pegue o checklist
receba o mapa
entre no canal / close friends
salve este framework
```

## Sinais Capturados

- salvamento
- compartilhamento (DM/Stories)
- comentario com palavra-chave
- resposta em story
- clique no link
- DM aberta
- site/perfil enviado
- pedido de analise
- join em Broadcast / Close Friends / lista WA

---

## Gates da doutrina (P0)

Antes de aprovar peca de Instagram:

1. Funcao no funil declarada
2. Aumenta confianca?
3. Proximo passo natural?
4. Motivo de SAVE, SHARE ou DM?
5. Descoberta: SEO nativo (keyword na 1a linha + texto na tela) + entrada no dominio privado?
6. Handoff + origin tag + first response asset?
7. Promessa indevida? (nicho regulado → checklist)

SLA de referencia: hot lead &lt;15 min no horario comercial; auto com valor em &lt;60s.

---

## Evitar

```text
CTA agressivo demais
conteudo so de venda
post sem proximo passo
formularios longos antes de valor
promessa sem prova visual
cold DM em massa
urgencia artificial continua
volume sem 1 ideia central por semana
peca sem save/share/DM motive
```
