## O que este grupo faz

Transforma clientes em fãs.
Fãs em promotores.
Promotores em canal de aquisição.

O cliente que fica e indica é o melhor ativo do sistema.

---

## Quando chamar

```
→ Para estruturar o pós-venda de um cliente novo
→ Para reativar clientes que pararam de responder
→ Para identificar risco de churn antes de acontecer
→ Para o cliente que precisa de presença ativa de marketing
→ Para planejar o relacionamento de longo prazo
```

Comando: `/relacionar`
