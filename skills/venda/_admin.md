## O que este grupo faz

Converte o desejo criado pelo marketing em decisão de compra.
Marketing aquece. Venda fecha.

---

## Quando chamar

```
→ Quando há um lead qualificado para abordar
→ Para preparar uma reunião comercial
→ Para estruturar o argumento de fechamento
→ Para responder objeções específicas
→ Para definir a proposta final
```

Comando: `/vender`

---

```

"Como posiciono o preço sem perder o cliente?"

```

## A distinção que este grupo guarda

```
Marketing fala para muitos.
Venda fala para um.

Marketing cria contexto.
Venda cria decisão.

Marketing pode esperar.
Venda não pode.
```

---

## Regra de ouro deste grupo

Lead qualificado sem abordagem rápida esfria.
Toda venda tem janela. Respeite o tempo.
