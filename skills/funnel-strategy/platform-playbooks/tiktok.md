# TikTok Funnel Playbook

TikTok deve ser tratado como:

```text
descoberta
cultura
tensao rapida
prova visual
busca comportamental
atencao de baixa friccao
```

---

## Funis Recomendados

```text
Video de tensao -> comentario -> recurso
Demonstracao rapida -> perfil -> link
Antes/depois -> DM -> analise
Serie curta -> comunidade -> oferta
```

---

## CTAs Recomendados

```text
comenta "mapa"
segue para ver a parte 2
manda seu nicho
pega o checklist no perfil
```

---

## Sinais Capturados

- comentario com palavra-chave
- follow apos video especifico
- clique no perfil
- DM com nicho/problema
- consumo de serie

---

## Regras

- Comecar com tensao clara, nao explicacao longa.
- Prova visual vale mais que promessa.
- CTA precisa ser leve e nativo do comportamento da plataforma.
- O perfil deve estar preparado para transformar atencao em proximo passo.

---

## Funnel Metadata Padrao

```md
## Funnel Metadata

- Funnel stage: awareness | problem-aware
- Intent level: low | medium
- Friction level: 0 | 1
- Expected lead signal: comment, follow, profile click, DM
- Qualification goal: identify problem category and niche
- Primary CTA: comment keyword or visit profile
- Secondary CTA: follow for next part
- Routing destination: profile link, DM, resource page
- Next best action: deliver low-friction resource or ask niche
```
